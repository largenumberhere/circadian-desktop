# Circadian Service
Quick and easy script files to update gnome's desktop settings to help with human circadian rythm / daylight cyles.
It prioritises ease of modification and reading, not formal correctness or user experience.

## Usage:
- Review `circadiandesktopwallpapertheme.sh` to see roughly how it works.
- Copy this folder to your desktop, call the folder `wallpapers`.
- and install it to systemd with the `.service` file provided.
- Modify `circadiandesktopwallpapertheme.sh` to your hearts content.

## Implementation Cheatsheet
 cp desktopcircadian.service ~/.config/systemd/user/

 systemctl --user restart desktopcircadian.service 
 systemctl --user status desktopcircadian.service 
(points to: `./backgroundupdate.sh`)

 gsettings get-keys org.gnome.desktop.background
 gsettings list-keys org.gnome.desktop.background
 gsettings get org.gnome.desktop.background picture-uri
 gsettings get org.gnome.desktop.background picture-uri-dark
 gsettings list-keys 
 gsettings list-schemas

gsettings get org.gnome.desktop.interface gtk-theme
'Yaru-red-dark'
gsettings get org.gnome.desktop.interface gtk-theme
'Yaru-dark'
gsettings get org.gnome.desktop.interface gtk-theme
'Yaru-blue'
gsettings get org.gnome.desktop.interface gtk-theme
'Yaru-olive'
